# Organização e Arquitetura de Computadores
Neste repositório estão todos os códigos desenvolvidos durante a realização a matéria Organização e Arquitetura de Computadores, que fiz em 2025/2 com o professor Ricardo Pezzuol Jacobi. O repositório contém todos os códigos Assembly RISC-V e VHDL elaborados no decorrer do semestre; aqueles para a parte de arquitetura da matéria (módulo 1) e estes para o projeto e implementação dos processadores explorados na disciplina: Uniciclo, Multiciclo e Pipeline. Além disso, o repositório também conta com os códigos LaTeX desenvolvidos para os relatórios dos laboratórios da disciplina, bem como com os PDFs desses relatórios.

Os roteiros de cada laboratório estão detalhados em arquivos `README.md` nos diretórios correspondentes a esses laboratórios.
